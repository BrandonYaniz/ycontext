# Roadmap

## v0.1

- Plain-text ingestion.
- SQLite storage.
- Filesystem document store.
- JSON Lines over Unix socket.
- YAML config.
- yllmd client boundary.
- Context profiles.
- Chunking and LLM boundary refinement.
- Leaf summaries.
- Merge summaries.
- Typed tags.
- Basic validation.
- Knowledge sets.
- Context assembly.
- Prompt rendering.
- CLI for inspection and testing.

## Later

- Markdown support.
- CSV support.
- HTML support.
- Code-aware ingestion.
- Entity resolution.
- Embeddings.
- More retrieval strategies.
- Package validation scoring.
- Better repair workflows.
- Server mode, if it proves useful.

## Not planned for the first build

- Windows support.
- GUI.
- OCR.
- PDF parsing.
- Cloud sync.
- Direct model serving.
